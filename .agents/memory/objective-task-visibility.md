---
name: Objective task visibility
description: The boundary between active tasks displayed on weekly objective detail and retained task history.
---

Completed tasks should not appear in the supporting-task list on weekly objective detail for either Admins or Managers. Completion can still contribute to an aggregate progress summary; the underlying task records, updates, and history remain available through their normal project and task views.

**Why:** The user explicitly wants the weekly objective page focused on remaining work without losing completed progress or history.

**How to apply:** Filter only the objective detail presentation. Never delete or rewrite completed task records to clear that list, and use the same display rule for both roles.
