---
name: Department icon identity
description: How department symbols should carry through objective surfaces without obscuring status.
---

Use the same simple department symbol on department and objective surfaces: code for Engineering, a flask for R&D, a shield for Data & Security, and a megaphone for Sales & Marketing. Set each in a distinct, colorful rounded-square background rather than substituting more complex symbols. For an objective, derive the department from its responsible manager; use a neutral fallback if no department can be resolved. Keep objective status in its own label or badge rather than changing the identity symbol by status.

**Why:** The user specifically corrected the icon redesign: the earlier, familiar symbols were better; the missing improvement was iOS-style color in the icon background. Stable symbols and colors make related work recognizable across roles and pages.

**How to apply:** Reuse the central department-symbol and color mapping on new department or objective UI. Preserve an explicit status indicator alongside objective identity.
