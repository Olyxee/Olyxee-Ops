---
name: People activity labels
description: Why the People directory separates last activity from account and employment status.
---

The People directory should describe recent Ops activity in plain relative time, while a person's detail view distinguishes employment status from sign-in access. Avoid using one generic "Status" label for online presence, employment, and account access.

**Why:** The user found the previous mixed status column hard to understand and supplied a simple "Last Active" reference with relative times.

**How to apply:** For future People UI changes, label each state by what it actually means. Activity refers to Ops sign-in or presence, not unrelated task history; no sign-in record should be shown as unknown rather than invented activity.
